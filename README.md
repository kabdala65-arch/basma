# 🎂 موقع بسمة — Birthday Website

موقع عيد ميلاد بـ React + Vite + Framer Motion. باسورد الدخول: `basma`

## التشغيل
```bash
npm install
npm run dev
```

## الميديا
- صور المعرض (9 صور): `public/images/photo1.jpg` … `photo9.jpg`
- صورة البروفايل: `public/images/profile.jpg`
- الفيديو: `public/video/our-video.mp4`
- الأغنية: `public/music/our-song.mp3`

(الموقع بيدور تلقائي على jpg / jpeg / png / webp للصور)

## النشر
`npm run build` ثم ارفع فولدر `dist` على Vercel أو Netlify.
